## 🚀 Em destaque

### 🤖 Robô de automação para verificação de equipamentos em ambiente SCADA
> **Status:** 🔧 em desenvolvimento

Projeto técnico criado no contexto das minhas atividades de verificação em sistemas de telecontrole. O objetivo é **reduzir tarefas manuais repetitivas**, **organizar resultados** e **apoiar a identificação de possíveis inconsistências**.

- Scripts em **PowerShell** para processar listas de equipamentos em **CSV**
- Organização e análise dos resultados em **Excel**
- Automação da interação com interface gráfica e análise de capturas de tela
- Em investigação: integração com dados via **OLE DB** (somente leitura) e uso de **OCR**

<sub>Por envolver um ambiente corporativo, o código e os detalhes internos não são publicados neste perfil.</sub>
