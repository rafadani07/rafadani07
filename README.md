### 🤖 Robô de automação para verificação de equipamentos em ambiente SCADA
![Status](https://img.shields.io/badge/status-em_desenvolvimento-F2994A?style=flat-square) ![PowerShell](https://img.shields.io/badge/PowerShell-5391FE?style=flat-square&logo=powershell&logoColor=white) ![Excel](https://img.shields.io/badge/Excel-217346?style=flat-square&logo=microsoftexcel&logoColor=white) ![CSV](https://img.shields.io/badge/CSV-6E7781?style=flat-square)

Projeto técnico criado no contexto das minhas atividades de verificação em sistemas de telecontrole, com o objetivo de **reduzir tarefas manuais repetitivas**, **organizar resultados** e **apoiar a identificação de possíveis inconsistências**.

- ⚙️ Scripts em **PowerShell** para processar listas de equipamentos em **CSV**
- 📊 Organização e análise dos resultados em **Excel**
- 🖱️ Automação da interação com interface gráfica e análise de capturas de tela
- 🔬 Em investigação: integração via **OLE DB** (somente leitura) e uso de **OCR**

<sub>🔒 Por envolver um ambiente corporativo, o código e os detalhes internos não são publicados aqui.</sub>
